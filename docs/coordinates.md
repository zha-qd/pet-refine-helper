# 坐标与识别说明

所有坐标相对于目标窗口左上角，包含窗口标题栏；它们不是屏幕绝对坐标。

```text
屏幕 x = 窗口左边 + 参考 x × 窗口宽度 / 777
屏幕 y = 窗口顶边 + 参考 y × 窗口高度 / 1396
```

## 总属性

总属性按单独提供的完整窗口截图 `762 × 1393` 校准，不应直接套用上面的参考尺寸。

| 属性 | 左上角 | 右下角 |
| --- | --- | --- |
| 盾兵生命 | 370, 590 | 548, 618 |
| 矛兵穿透 | 370, 674 | 548, 702 |
| 矛兵生命 | 370, 757 | 548, 785 |
| 射手穿透 | 370, 840 | 548, 868 |
| 射手生命 | 370, 923 | 548, 951 |

这些区域读取类似 `33.75%/44.69%` 的文本，避开红绿增减值。OCR 置信度不足 0.80、格式错误、当前值大于上限等结果会拒绝使用。连续两次相同才接受；确认后还必须与预期值及原上限完全匹配。

## 更换布局时

1. 停止助手，在完整游戏窗口截图上确定目标区域。
2. 更新 `REGIONS`、`BUTTONS` 或 `TOTAL_ROWS`，必要时更新对应参考宽高。
3. 检测窗口并运行“校准”，检查按钮位置。
4. 通过调试截图核对变化值区域；总值区域目前没有独立的可视化编辑器。
5. 小批量运行并对照游戏实际数值。

线性缩放不能修正界面内容重新排版、不同标题栏高度或 DPI 差异；不要将它视为通用自动定位功能。
